## Truestamp Community Hub 👋

This repository holds the [Truestamp organization discussions](https://github.com/orgs/truestamp/discussions) and an issue tracker for anything that doesn't belong to a single repository.

[Truestamp](https://www.truestamp.com) provides a platform that lets you create commitments that attest to the timestamp, integrity, and provenance of your most important data by cryptographically binding it to public blockchains.

### Where to Go

| You want to… | Go to |
| --- | --- |
| Ask a question or start a conversation | [Discussions](https://github.com/orgs/truestamp/discussions), or [Q&A](https://github.com/orgs/truestamp/discussions/categories/q-a) for questions |
| Report a bug in a specific project | That project's repository on the [repositories page](https://github.com/orgs/truestamp/repositories) |
| Report a bug when you're not sure which repository it belongs to, or a problem with the Truestamp service | [A new issue in this repository](https://github.com/truestamp/discussions/issues/new/choose) |
| Suggest a feature or give product feedback | The [feedback board](https://truestamp.userjot.com/board/features) |
| Report a security vulnerability | Privately, as described in the [security policy](https://github.com/truestamp/.github/blob/main/SECURITY.md). Never in a public issue or discussion. |
| Get help using Truestamp | The [help center](https://www.truestamp.com/support), or email [support@truestamp.com](mailto:support@truestamp.com) |
| Chat | [Discord](https://discord.gg/vQgKEEu) or X/Twitter [@truestamp](https://x.com/truestamp) |

### Policies

All use of Truestamp services, including the issue tracker and public discussions, is governed by the Truestamp policies, and your participation indicates acceptance of them.

- [Code of Conduct](https://github.com/truestamp/.github/blob/main/CODE_OF_CONDUCT.md)
- [Privacy Policy](https://www.truestamp.com/privacy-policy)
- [Terms of Service](https://www.truestamp.com/terms-of-service)

The Code of Conduct, the [contributing guide](https://github.com/truestamp/.github/blob/main/CONTRIBUTING.md), and the [security policy](https://github.com/truestamp/.github/blob/main/SECURITY.md) live in [truestamp/.github](https://github.com/truestamp/.github) and apply to every Truestamp repository that doesn't have its own.
